## 📋 عن المشروع

**FelFel Manager** نظام إدارة أعمال كامل مخصص لمشاريع تجارة الفلفل والمخلل. يساعدك على:

- 🛒 تسجيل شراء الشكاير والبراميل
- 🌶️ إدارة الإنتاج والتجهيز
- 💰 إصدار الفواتير والتحصيل
- 👥 متابعة العملاء والديون
- 👷 إدارة العمال بأجر يومي
- 💵 تتبع الخزنة والحركات المالية
- 📊 تقارير شاملة وأرباح
- 🤝 توزيع الأرباح بين الشركاء

---

## ✨ المميزات

### 🎯 متعدد المنتجات
- فلفل (يحتاج تجهيز: وزن قبل/بعد + تكلفة تقطيع)
- مخلل طرشي وحراق (شراء برميل وبيع مباشر)
- إضافة منتجات غير محدودة من الإعدادات

### 💼 محاسبة احترافية
- حساب تكلفة الكيلو الحقيقية تلقائيًا
- COGS (تكلفة البضاعة المباعة) دقيقة
- صافي ربح = مبيعات − COGS − مصاريف − أجور
- توزيع الربح تلقائي بين الشركاء
- فصل الربح المحاسبي عن النقدية المتاحة

### 👷 نظام العمال
- أجر يومي ثابت لكل عامل
- تسجيل أيام العمل مع سجل كامل
- متابعة المستحق والمدفوع والمتبقي

### 📊 التقارير
- صافي الربح (سنوي/شهري/مخصص)
- مبيعات حسب العميل/المنتج
- ديون العملاء المتأخرة
- مخزون متبقٍ وقيمته
- مقارنة الفترات
- تصدير CSV و Excel

### 🔒 الأمان
- PIN حماية عند الفتح
- نسخ احتياطي كامل (JSON)
- سجل نشاط لكل التعديلات
- لا يتم إرسال أي بيانات لأي سيرفر

### 🎨 الواجهة
- عربي (RTL) / إنجليزي (LTR)
- وضع ليلي / نهاري
- تصميم متحرك احترافي
- يعمل على الموبايل والكمبيوتر
- PWA — يمكن تثبيته كتطبيق
